Connecter votre compteur Shelly à Cysan

Cette page vous aide à installer le petit programme qui envoie les relevés de votre compteur Shelly à Cysan. Comptez environ 10 minutes.

Ce qu'il vous faut

  • Un ordinateur Windows allumé et connecté à Internet.
  • Docker Desktop installé et démarré (l'icône de baleine près de l'horloge).
  • Le message de Cysan avec votre code personnel.
  • Le dossier où sont enregistrés vos relevés Shelly. L'installateur le trouve en général tout seul.

1. L'invitation

Cysan vous envoie un message (WhatsApp ou e-mail) avec le lien de cette page et votre code personnel, par exemple ABCD-EFGH-JKMN-PQRS-TVWX. Le code ne fonctionne qu'une seule fois, pendant 48 heures. Gardez-le pour vous.

Pas de code, ou code expiré ? Demandez-en un nouveau à Cysan.

2. L'installation

  1. Démarrez Docker Desktop et attendez qu'il indique qu'il fonctionne.
  2. Téléchargez le fichier adapté à votre ordinateur (voir « Quel fichier choisir ? » ci-dessous).
  3. Faites un clic droit sur le fichier téléchargé et choisissez « Extraire tout ».
  4. Dans le dossier extrait, double-cliquez sur Install. Si Windows affiche un avertissement bleu, cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ».
  5. Quand la fenêtre demande Enrollment code, tapez votre code puis appuyez sur Entrée. Ce que vous tapez reste invisible, c'est normal.
  6. Quand elle vous montre le dossier de vos relevés et demande si c'est le bon, appuyez sur Entrée pour dire oui.

Quel fichier choisir ?

Ouvrez Paramètres, puis Système, puis « Informations système » (ou « À propos de »), et regardez la ligne « Type du système ».

Télécharger pour la plupart des ordinateurs56 Mo
« Type du système » indique « processeur x64 » Télécharger pour les ordinateurs ARM58 Mo
« Type du système » indique « processeur ARM »

3. C'est terminé

Quand la fenêtre affiche DONE, l'installation est finie. Votre ordinateur envoie désormais les relevés tout seul. Laissez Docker Desktop allumé. Cysan vous confirmera la bonne réception de vos données.

Un problème ?

  • « The code was refused » : vérifiez votre code. S'il a déjà servi ou s'il a expiré, demandez-en un nouveau à Cysan.
  • « Docker did not answer » : démarrez Docker Desktop, attendez une minute, puis double-cliquez de nouveau sur Install.
  • « This image is for CPU type… » : vous avez pris l'autre fichier. Téléchargez le bon et recommencez : votre code n'a pas été utilisé.
  • Autre chose : envoyez à Cysan une photo de la fenêtre.

Votre code et le dossier « secrets » créé par l'installateur sont personnels : ne les partagez jamais. Le programme lit seulement votre dossier de relevés et ne le modifie jamais.

Connect your Shelly meter to Cysan

This page helps you install the small program that sends your Shelly meter's readings to Cysan. It takes about 10 minutes.

What you need

  • A Windows computer, switched on and connected to the internet.
  • Docker Desktop installed and running (the whale icon near the clock).
  • The message from Cysan with your personal code.
  • The folder where your Shelly readings are saved. The installer usually finds it on its own.

1. Invitation

Cysan sends you a message (WhatsApp or e-mail) with the link to this page and your personal code, for example ABCD-EFGH-JKMN-PQRS-TVWX. The code works only once, for 48 hours. Keep it to yourself.

No code, or the code has expired? Ask Cysan for a new one.

2. Installation

  1. Start Docker Desktop and wait until it says it is running.
  2. Download the file for your computer (see "Which file?" below).
  3. Right-click the downloaded file and choose "Extract All".
  4. In the extracted folder, double-click Install. If Windows shows a blue warning, click "More info", then "Run anyway".
  5. When the window asks for the Enrollment code, type your code and press Enter. What you type stays hidden; that is normal.
  6. When it shows the folder of your readings and asks if it is the right one, press Enter for yes.

Which file?

Open Settings, then System, then "About", and look at the line "System type".

3. Done

When the window shows DONE, the installation is finished. Your computer now sends the readings by itself. Leave Docker Desktop running. Cysan will confirm that your data has arrived.

A problem?

  • "The code was refused": check your code. If it was already used or has expired, ask Cysan for a new one.
  • "Docker did not answer": start Docker Desktop, wait a minute, then double-click Install again.
  • "This image is for CPU type…": you took the other file. Download the right one and start again: your code was not used.
  • Anything else: send Cysan a photo of the window.

Your code and the "secrets" folder the installer creates are personal: never share them. The program only reads your readings folder and never changes it.
