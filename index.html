Cysan Shelly sync

Enrollment of a computer that sends Shelly meter data to Cysan · Inscription d'un ordinateur qui envoie les données d'un compteur Shelly à Cysan

EnglishFrançaisDownloads / Téléchargements

English

You need: a Windows computer with Docker Desktop running, the data folder of your Shelly exports, and the one-time code Cysan sent you. The code works once, within its validity period.

  1. Download the installer and the image file for your computer's processor (most computers: x86-64) from the table below.
  2. Check both SHA-256 values in PowerShell: Get-FileHash <file> -Algorithm SHA256. They must equal the table's.
  3. Unzip the installer, open PowerShell in its folder, and run (one line):
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -ImageTar <image file> -ImageSha256 <its SHA-256>
  1. Type the code when asked (typing is hidden). The installer checks Docker, finds your data folder and asks you to confirm it, enrolls this computer and starts the sync.
  2. Keep the install folder's secrets folder private: never copy, e-mail or upload it.

Your computer's private key is created on your computer and never leaves it. The sync reads your data folder read-only. Never share your code; if you think someone else saw it, tell Cysan so it can be cancelled.

Français

Il vous faut : un ordinateur Windows avec Docker Desktop démarré, le dossier de données de vos exports Shelly, et le code à usage unique envoyé par Cysan. Le code ne sert qu'une fois, pendant sa durée de validité.

  1. Téléchargez l'installateur et le fichier image correspondant au processeur de votre ordinateur (la plupart des ordinateurs : x86-64) dans le tableau ci-dessous.
  2. Vérifiez les deux SHA-256 dans PowerShell : Get-FileHash <fichier> -Algorithm SHA256. Ils doivent être identiques à ceux du tableau.
  3. Décompressez l'installateur, ouvrez PowerShell dans son dossier et lancez (une seule ligne) :
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -ImageTar <fichier image> -ImageSha256 <son SHA-256>
  1. Saisissez le code quand il est demandé (la saisie est masquée). L'installateur vérifie Docker, trouve votre dossier de données et vous demande de le confirmer, inscrit cet ordinateur et démarre la synchronisation.
  2. Gardez privé le dossier secrets du dossier d'installation : ne le copiez, ne l'envoyez et ne le téléversez jamais.

La clé privée de votre ordinateur est créée sur votre ordinateur et ne le quitte jamais. La synchronisation lit votre dossier de données en lecture seule. Ne communiquez jamais votre code ; si vous pensez que quelqu'un d'autre l'a vu, prévenez Cysan pour qu'il soit annulé.
